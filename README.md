# Odd or Even Checker
A simple Python program that accepts a number from the user and determines whether it is **odd or even**.
## Features
- Accepts positive and negative numbers
- Uses the `%` operator
- Gives a clear result

## How to Run
1. Make sure Python is installed.
2. Run the program:
```bash
python odd_even.py
```
3. Enter a number when prompted.
## Example
```text
Enter a number: -7
Odd
```
```text
Enter a number: 10
Even
```
